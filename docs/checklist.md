# リリース前 手動E2Eチェックリスト

スキーマ変更・大きな機能追加のたびに一巡すること。

## セキュリティ
- [ ] `npm run verify:rls` が全チェック合格する

## 公開画面（ログイン不要）
- [ ] トップで団体カード一覧と地図が表示される
- [ ] キーワード検索・テーマ絞り込み・エリア絞り込みが効き、件数表示が変わる
- [ ] カード / 地図ピンをクリックすると詳細パネルが開く
- [ ] 詳細パネルの「この団体のページを開く」で `/org/[id]` が開く
- [ ] `/org/[id]` のURLをLINE等に貼るとOGP（団体名・説明）が表示される
- [ ] スマホ幅でリスト⇄地図の切替ができる
- [ ] フッターからプライバシーポリシー・運営者情報が開ける

## 申請 → 承認 → 公開の一連フロー
- [ ] `/apply` から必須項目のみで申請を送信 → 完了画面が表示される
- [ ] `/admin/login` でログインできる（誤ったパスワードでエラーが出る）
- [ ] 申請一覧に「審査待ち」で表示される
- [ ] 審査画面で「住所から位置を検索」でピンが立つ・地図クリックで微調整できる
- [ ] 承認 → 公開トップに**即時**表示される（リロードのみで反映）
- [ ] 団体一覧から「非表示にする」→ 公開トップから即時消える
- [ ] 「公開する」→ 再度表示される
- [ ] 却下した申請が「却下」表示になり、公開画面に出ない

## 管理画面の保護
- [ ] 未ログインで `/admin/applications` を開くとログイン画面へリダイレクトされる
- [ ] admin_users に登録されていないAuthユーザーではログイン後も管理画面に入れない
